Detail Proyek: Turtle Race

Game Balap Kura-Kura

Turtle Race adalah game balap kura-kura yang memungkinkan pemain menebak warna kura-kura yang akan menjadi pemenang.

Game ini memiliki enam pilihan warna: merah, oranye, kuning, hijau, biru, dan ungu. Pemain memilih warna yang diprediksi akan menang sebelum balapan dimulai.

Setelah balapan selesai, game menampilkan kura-kura pemenang dan memberi tahu apakah tebakan pemain benar atau belum tepat. Pemain dapat menekan tombol spasi untuk memulai balapan berikutnya.

Fitur Game

  • Enam pilihan warna kura-kura.
  • Sistem menebak pemenang balapan.
  • Lintasan dengan garis start dan finish.
  • Hasil balapan dan status tebakan pemain.
  • Tombol spasi untuk balapan berikutnya.
